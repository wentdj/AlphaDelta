# Delta-Alpha static site

This is a plain HTML and CSS site for GitHub Pages. It has no build step or server-side dependencies.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing this site and the `/ (root)` folder, then save.

GitHub Pages will publish `index.html` from the repository root. The supplied photos are in `assets/images/`.
